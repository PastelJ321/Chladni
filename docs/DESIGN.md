# Chladni v0.4 설계

2026-11-17. 실험·분석·장치의 세 작업 공간은 같은 Config, ModalResult, Field, Run을 참조한다.

## 화면과 재질

그라파이트 상단, 웜 실버 프레임, 310 px 접이식 설정 패널과 큰 차콜 장면을 사용한다. 핵심 주파수·입자군·실행은 기본 화면, 밀도·마찰·FEM은 접이식이다. 연출 도구는 장면 아래 도크에 둔다. 모바일은 설정 서랍으로 전환한다. IBM Plex Sans KR, 주요 입력 13 px, 보조 정보 12 px 수준, 데이터 청회색/모래색을 사용한다.

Glass는 카메라·재생·연출·부품 팝오버에 한정한다. 다중 내부 하이라이트, 가장자리 반사, 내부 음영, 반투명 명암과 배경 블러로 얇은 두께를 근사한다. 광학 굴절은 계산하지 않는다. 미지원 및 투명도 감소 환경에는 불투명 CSS 폴백이 있다.

판의 베벨·관통부, 육각 소켓·나사산, 상하 와셔·연결부, 두께 있는 프레임·콘, 코일·자석·고무, 베이스·케이블을 독립 부품으로 구성한다. 기준 접촉 위치는 조립 후 정확히 복원한다. 연결 그래프와 assetContract는 사진/CAD 자산 교체 경계를 유지하지만 완성된 GLB 가져오기 UI는 없다. 실측 장비의 디지털 트윈으로 표시하지 않는다.

미세 방향성 normal/roughness는 선형 데이터다. 콘/고무의 섬유 bump, 알루미늄/스틸/구리를 구분한다. 로컬 Poly Haven CC0 HDR를 PMREM으로 사용하고 실패 시 생성 스튜디오 환경으로 대체한다. 중성 키·필·면광원, VSM 그림자, 작업대와 바닥으로 깊이를 만든다. LTC 라이브러리는 지연 로드한다. Bloom·색수차·광학 DOF·유리 입자 굴절은 없다.

## 계산 수명과 캐시

SolverClient는 유휴 Worker를 유지한다. 진행 중 요청을 취소하면 Worker를 종료하지만 메인 스레드의 최근 3개 모드를 다음 Worker에 전달한다. 입력은 160 ms debounce하며 완료 시 요청 번호와 조건 키를 검사한다. Worker 캐시는 모드 3개·응답 24개·스윕 4개다.

| 변경                                           | 처리                                    |
| ---------------------------------------------- | --------------------------------------- |
| 판 치수·탄성·밀도·포아송비·경계·구속 절점·메시 | FEM 재계산                              |
| 감쇠·구동 세기·구동점                          | 모드 재사용, 응답/스윕 갱신             |
| 선택 주파수                                    | 모드/응답 곡선 재사용, 선택 응답만 계산 |
| 입자 조건                                      | 판 결과 유지, Run 무효화                |
| 카메라·표시·레이어                             | 물리 계산 없음                          |

재료 이름과 해석에 무관한 설정은 FEM 키에서 제외한다. 중앙 지지는 실제 해석 절점으로 키를 만든다. 과거 전체 판 키도 파일에서 받아들이며 원본 기록은 수정하지 않는다.

## 입자와 시간

호환을 위해 sand/salt 두 저장 슬롯을 유지하고 material 속성으로 규사·소금·설탕·유리 비즈·사용자 정의를 선택한다. 평균 입경·균등 분포폭·밀도·마찰·형태·체 구간이 독립적이다. 혼합률은 개수 비율이다. 실제 입경으로 질량과 운동을 계산하고 표시 색·거칠기·배율은 ViewSettings에 둔다.

120 Hz Double 적분을 유지한다. 각 시간 단계에서 인접 준정상 주파수 장의 실수·허수를 보간한 뒤 가속도 에너지를 구한다. 진폭만 보간하지 않는다. 과도해석·공기 유동은 아니다. 무구동·임계 미달·무이동·이동 관찰, 계산 대기·실패를 구분한다.

보통 20 Hz Float32 위치/거리 체크포인트를 저장한다. 약 96 MiB 예산에서는 저장 간격만 늘린다. 이진 탐색으로 실제 시간의 양쪽 체크포인트를 찾고 선형 보간하며 마지막 비균일 시간도 처리한다. 새 물리 현상을 만들지 않는다. 절대 PlaybackClock을 사용해 프레임 드롭에도 재생 시간이 일관된다. 탭이 숨겨지면 일시 정지한다. React 상태 표시와 GPU 재생 빈도를 분리한다.

## GPU 계층

PlateField의 Float32 RGBA 텍스처(실수·허수·진폭)를 판·입자·그림자가 공유한다. 수동 bilinear 샘플링으로 float-linear 확장에 의존하지 않는다. 판 변형·노멀·데이터 색을 셰이더에서 계산한다. 내부 정점이 있는 조밀한 사각 외곽 환형 메시로 RoundedBox의 큰 면 삼각형 문제를 해결했다. 렌더링 메시와 BFS 계산 메시를 구분한다.

ParticleRenderer는 두 위치 끝점과 정적 입경·시드·색·접촉 높이를 GPU에 둔다. 기록 경계에서 끝점 버퍼를 교환하고 새 끝점만 전송한다. 그 사이에는 보간 uniform만 바뀐다.

- 원경: 단일 정점 InstancedBufferGeometry GPU 스플랫, 깊이 검사·종별 외곽/음영. 실제 크기 모드는 subpixel 면적으로 커버리지를 줄인다.
- 중간: 3–6 CSS px 사이에 고정 시드로 스플랫/PBR을 전환한다.
- 접사: 화면 내 군별 최대 4,096개를 PBR 해석하고 나머지는 스플랫을 유지한다. 접촉 어둠은 국소 근사이고 입자별 shadow map은 아니다.
- 실제 크기는 물리 지름, 관찰용은 max(물리 지름 × 배율, 최소 화면 지름). 최대 100k 표시는 최대 50k 적분 입자의 대표 시각 표본이다. 추가 표시는 과학 통계에 포함하지 않는다.

등고선·궤적은 장/선택/기록 구간 변경 시 갱신한다. 16×16 밀도는 해당 레이어에서만 체크포인트별 캐시한다. 밀도와 복소 스윕장의 시간 해상도 차이는 남는다. 품질 제어는 DPR과 접사 PBR만 낮추며 물리 수·메시를 바꾸지 않는다. DPR 상한은 표준 1.5, 저사양 1이다.

## 연출과 저장

AnimationDirector는 연구 데이터를 수정하지 않는다. 전경 9 s, 분해·조립 18 s, 공진 12 s, 입자 이동 14 s, 매크로 10 s, 실측 비교 10 s. quintic ease, 시간차, 위치·타깃·FOV·정지 구간을 제어한다. 초점 거리는 카메라 속성이고 DOF는 아니다. 나사 해제는 회전과 축 이동을 연결하며 정지·역방향 재생·스크럽과 원점 복귀를 지원한다.

입자 연출은 Run 진행률을 읽고 접사 전환 시 변위 배율을 1로 낮춘다. 연출 외 재생은 선택한 정지 위상을 유지한다. 수백 Hz 물리 진동과 화면의 연출 시간을 구분한다. 직접 드래그하면 자동 카메라가 중단된다.

캡처 때만 별도 render target으로 최대 DPR 2·폭 3840 px를 렌더한다. preserveDrawingBuffer는 상시 사용하지 않는다. PNG에 UI·실측은 포함하지 않는다. geometry/material/texture/worker/컨텍스트를 해제한다.

chladni/4 바이너리는 12바이트 헤더, JSON 명세, 중복 제거된 Float32 LE 블록이다. JSON은 Float32 바이트의 base64 태그다. 과거 /2, /3 일반 배열과 키를 보존한다. CSV는 스크럽 시간의 보간값과 단위를 기록한다. 내보내기 직렬화는 현재 메인 스레드이므로 큰 다중 기록은 일시 정지를 유발할 수 있다.
