# 연구실 구조와 디자인

2026-11-24. 기존 로컬 저장소와 계산·기록을 유지한 통합 개편이다. 버전별 신규 프로젝트를 만들지 않는다.

## 코드 감사와 변경 판단

기존 FEM의 Navier 기준 검증, 24모드 응답, Persistent Worker, 복소 스윕, Float32 기록, GPU PlateField/ParticleRenderer는 유지했다. 모드 캐시와 과학 데이터는 카메라·표시 수·재질·연출 상태에서 분리한다. 교육용 코사인 모델은 연구 계산에 사용하지 않는다.

기존 모델의 중앙 관통 볼트는 실제 장치 설명과 일치하지 않았다. `device.ts`의 현재 장치 프로필은 무관통 판·임시 접착 연결부로 시작하고 실제 형상/치수 미확인을 표시한다. 강화 설계와 이상 장치에 별도 프로필을 사용한다. 과거 세션에 프로필이 없으면 기존 볼트 모델과 계산을 보존한다. 장치 사진·CAD가 없으므로 절차적 외형을 정밀 실측 모델로 주장하지 않는다.

기존 평균 이동 거리·좌측 절반 비율만으로는 분리 연구를 평가하기 어려웠다. 같은 FEM 장과 실제 적분 입자를 사용하는 마디/배 비율, 군별 밀도, 총변동거리, 영역 순도/회수율과 반복 실험 편차를 추가했다. 측정 구역·분모·개수/질량 기준을 함께 저장한다. 기존 metrics API는 과거 파일/CSV 호환용으로 남겼다.

밝은 회색 UI와 큰 흰 소금 블록, 판과 구동부의 연결을 가리는 외형을 v0.4 실제 캡처에서 확인했다. 심해색 정보 위계, 별도 유리 도구, 접사 구도·결정 형태·미세 법선·조명으로 변경했다. 물리 입경을 키워 가시성을 해결하지 않는다.

## 한 세션, 세 작업 공간

| 공간 | 핵심 역할                                                                          |
| ---- | ---------------------------------------------------------------------------------- |
| 실험 | 장치 프로필, 주파수·구동 진폭, 독립 입자군, 스윕/입자 계산, 시간 재생              |
| 분석 | 응답 곡선, 모드·진폭·마디선·밀도·궤적 레이어, 초기/최종·기록 비교, 실측 정합, 보정 |
| 장치 | 출처·실측/추정/기본값·불확도, 개념 외형/CAD 참조, 분해·조립·단면·투시              |

저장·내보내기·발표는 도구다. 장면 연출 도구는 캔버스 아래에 배치하고 실험 재생과 구별한다. 고급 FEM/접촉 모델은 접이식 패널에 둔다. 새로운 작업 공간이 결과를 복제하거나 초기화하지 않는다.

## 데이터와 계산

- `experiment/device.ts`: 장치 프로필·측정 출처·미지값·추정 범위·사진·관측. 지원되는 숫자만 Plate/Drive에 적용한다. 프로필 라이브러리는 세션에 보존한다.
- `solver/connector.ts`, `compliantResponse.ts`: 평균 접촉 패치의 강성/질량과 비대각 감쇠. 기존 강체 구속 경로는 프로필 없는 기록에 유지한다.
- `solver/calibration.ts`, `calibrationWorker.ts`: 구간 내 한 변수 보정. 모드 대응·출처·보정/검증을 요구한다. 원래 모델과 잔차를 보존한다.
- `simulation/particles.ts`: 기존 드리프트, 시드 초기화, 보간. `contact.ts`: 실제 순간 FEM 법선/속도와 구형 충격·각속도, 중력, 선택 항력. 계산 예산을 초과하면 명시적으로 거부한다.
- `analysis/metrics.ts`: 실제 적분 표본만 분석. `registration.ts`: 네 모서리의 호모그래피 및 역방향 bilinear 원근 보정. 자동 입자 분류는 없다.
- `io/session.ts`: 과거 /2–/4와 신규 /5. Float32 바이너리·JSON·모델/관측/보정 검증. 출처와 메모만 바뀌면 결과는 유지하고, 계산 없는 조건 파일을 열면 이전 결과는 비운다.

## 렌더링과 자산 수명

PlateField의 복소 장 텍스처를 판·입자·그림자·등고선이 공유한다. 판의 정점·법선·데이터 색은 GPU에서 계산한다. ParticleRenderer는 정적 입경/종/시드와 두 Float32 기록 끝점의 위치·공중 간격을 분리한다. 새 기록 구간에서만 끝점을 업로드하고 프레임 사이에는 uniform으로 보간한다.

접사는 화면 크기 기반 LOD로 스플랫과 PBR 메시를 결정적으로 전환한다. 실제 크기와 확대 표시를 독립 저장한다. 소금은 얇은 베벨·결정면·미세 법선을 사용하고 접사 카메라는 표면을 조금 더 넓게 관찰한다. 외형의 비구형 결정과 접촉 모델의 등가 구 가정을 구별한다.

`scene/deviceAsset.ts`는 출처·길이 단위·Y-up/XZ 판 좌표·필수 부품 매핑을 확인한 로컬 내장형 GLB/GLTF만 읽는다. 외부 URI는 차단한다. 원래 부품 변환을 보존하고 계층별 world transform으로 분해·재조립한다. 가져온 CAD는 FEM에 자동 변환되지 않는다. Renderer는 참조만 소유하고 App이 자산을 교체/해제한다.

접착/볼트 절차적 모델을 캐시하고 재사용한다. 맵의 색상 공간과 법선 용도를 구분한다. 로컬 CC0 HDRI, 면광원과 차가운 fill을 사용한다. Bloom·네온·색수차는 없다. 별도 캡처 target을 사용하며 preserveDrawingBuffer를 상시 켜지 않는다. WebGL 컨텍스트가 손실되면 재생/연출을 멈추고 과학 데이터를 유지한 채 렌더러를 재구성한다.

## Deep Oceanic Instrument

배경 #071A2B, 계층 surface #102D40 / #174359, 상호작용 #42B6C6, 입자/주의 강조 #D7A363, 텍스트 #EAF4F6 / #A8C6D2. 단일 청록 면으로 채우지 않고 패널·작업 공간·장면의 명도를 구별한다. IBM Plex Sans KR을 로컬 번들로 제공하며 장식 이탤릭·슬로건·QJ 이니셜은 없다. 주요 수치와 단위는 tabular 정렬한다.

Liquid Glass는 카메라·재생·부품·연출 도구에 제한한다. 가장자리의 이중 하이라이트, 내부 음영, 곡면에 대응하는 반사 그라디언트, 청록 틴트·절제된 backdrop blur와 불투명 폴백을 조합한다. CSS의 굴절 근사이며 광학적으로 정확한 굴절/DOF라고 표시하지 않는다. 계산 설정 면은 읽기 쉬운 불투명 계층이다.

## 연출과 발표

AnimationDirector의 시간축은 실험 데이터와 독립이다. quintic easing, 부품별 지연·나사 축 회전, 위치·타깃·FOV·정지 구간을 유지한다. 전경·분해/조립·공진·입자 형성·접사·실측 비교 시퀀스를 한 타임라인에서 재생/역재생/스크럽한다. 직접 OrbitControls 조작이 시작되면 자동 카메라를 중단한다. 정지하면 저장한 원래 시점을 복원한다. 사용자가 저장한 카메라 북마크도 세션에 남긴다.

발표는 기존 세션 위의 집중 모드이며 실제 Fullscreen API를 사용한다. 조건 입력을 숨기고 저장된 기록 선택·관찰·연출을 제공한다. 저장 계산을 즉석 계산으로 표시하지 않는다. 서비스 워커는 production 번들의 로컬 JS/폰트/HDRI를 사전 캐시한다. 기기 보관은 명시적인 IndexedDB 세션 저장이며 외부 영상/CAD 원본은 별도 재연결한다.

## 과학적 한계

미측정 파라미터를 실물값으로 만들지 않는다. 단일 변수 보정은 디지털 트윈 정확도 인증이 아니다. 등가 연결부는 접착부 실패·흔들림·비선형 기울기와 스피커 전달함수를 해석하지 않는다. 독립 구형 접촉은 DEM·응집·실제 결정 접촉·유동을 제외한다. 역 클라드니와 실제 혼합물 분리 정확도는 검증되지 않았다. 단면은 실제 clipping plane이며 폐곡면 cap은 아직 없다. 33개 준정상 복소 응답은 판의 과도응답 해석이 아니다.
