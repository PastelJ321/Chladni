# Chladni v0.2 — 모델과 인터페이스

2026-11-12. 범위는 판 FEM 및 재현 가능한 입자 운동 근사를 포함하는 실험실 기반 구현이다. 전체 요청의 모든 고급 기능을 완료한 버전은 아니다.

## 작업 공간

실험 설계 → 가상실험 → 결과 분석 → 장비 구조 → 연구 기록 → 발표. 독립적인 페이지를 만드는 대신 공통 Config·ModalResult·Field·Run을 유지한다. 17개 뷰 메뉴는 없애고 분석 레이어와 구조 도구로 배치했다.

차콜 상단·탐색 바·작업 공간 프레임 안에 명도를 낮춘 실버 그레이 설정·분석 패널을 배치한다. 초기 v0.2의 흰 면적이 너무 넓다는 피드백에 따라 이전 버전의 차분한 분위기와 새 정보 구조를 결합했다. 실버 도구를 중성 차콜 작업대와 분리한다. Chladni를 제품명으로, QuadraJ를 출처로 표시한다. IBM Plex Sans KR, 본문 12–13px, 큰 수치는 39px다. 이탤릭 세리프·QJ 마크·거대 영문 제목은 제거했다. Glass는 카메라·레이어·상태·부품·발표 도구에만 적용한다. CSS 표현에는 광학적 굴절이 없으며 지원되지 않는 브라우저에는 불투명 대체 스타일을 제공한다.

## 판 FEM

BFS는 각 절점에서 w, ∂w/∂x, ∂w/∂y, ∂²w/∂x∂y를 갖는 C¹ tensor-product cubic Hermite 요소다. 균일 직사각형 격자에서 16 DOF/요소를 사용한다. 내부 DOF는 셀 dx,dy로 무차원화한 기울기를 사용한다.

- 굽힘 강성 D = E h³ / [12(1−ν²)]. 곡률은 [wxx,wyy,2wxy].
- Ke = ∫ Bᵀ Db B dA, Me = ∫ ρh Nᵀ N dA. 4×4 Gauss 적분.
- Kφ = ω²Mφ. Cholesky로 표준 대칭 문제로 변환하고 ml-matrix의 대칭 고유치 알고리즘 사용.
- φᵀMφ = 1. 잔차 ||Kφ−λMφ||/||Kφ||를 저장한다.
- 단순지지는 변의 w와 접선 방향 미분을 구속해 변 전체 w=0을 유지한다. 고정변은 관련 Hermite DOF를 구속한다.
- 중앙 고정은 최근접 절점의 네 DOF를 구속한다. 실제 유한 체결 패치의 해가 아니며 위치도 격자에 맞춰진다. 이 조건의 실험적 정확도를 주장하지 않는다.
- 최대 24개의 저차 모드를 보존한다. 절단 오차·고주파·국부 응답은 메시와 모드 수 수렴을 별도로 검토해야 한다.

점 힘의 모달 하중은 F φ(xd,yd). 고정부 변위 Y의 하중은 ω²Y φᵀMr이며 r은 강체 수직 병진이다. 이때 절대변위는 상대 응답에 Y를 더한다. 구속점의 점 힘은 변위를 만들지 않지만 고정부 운동은 응답을 만들 수 있다. 전기 입력이나 스피커 전달함수는 추정하지 않는다.

복소 응답 qi = Fi / [ωi²−ω²+j2ζωiω]. 스윕은 지정 범위의 정상 응답을 계산하고 이산 국소 최대를 공진 후보로 추출한다. 모든 고유모드가 구동 가능한 것은 아니므로 고유주파수와 응답 피크를 구분한다. 그래프의 응답은 질량 가중 상대 RMS 변위이고 3D는 절대변위다. 공진 후보는 샘플 간격의 해상도 제한을 갖는다.

## 입자 운동

120 Hz 고정 적분에서 판 가속도/중력 비 Γ를 사용한다. Γ≤1이면 이동성 게이트가 0이며 무구동에서 강제로 패턴을 만들지 않는다. 입경², 경험계수, 마찰·형태 근사 계수와 ∇Γ²로 목표 이동 속도를 계산한다. 속도는 0.03 m/s 상한을 둔다. 밀도와 입경은 Stokes 완화시간 τ=ρd²/(18μair)에 들어간다. 이는 작은 Reynolds 수에서만 타당한 선형 항력의 근사이고 건식 분리 법칙을 의미하지 않는다.

미해상 변동은 시드 고정 PRNG로 생성한다. 입경은 평균 ± 편차의 균등분포, 혼합 비율은 시드로 표본화한다. 경계는 입경을 고려한 반사 조건이다. 실제 가장자리 낙하·손실은 계산하지 않는다. 입자 간 충돌·정확한 접촉 마찰·공기 속도장·역 클라드니는 미구현이다.

고정 주파수는 하나의 FEM 장을 사용한다. 입자 스윕은 33단계 준정상 FEM 장을 저장하고 시간에 맞는 장으로 전환한다. 과도응답이나 연속 chirp 적분이라고 부르지 않는다. 3D·분석·입자는 저장된 같은 장을 참조한다. Run은 실제 적분으로 생성된 가변 길이 결과이며 20 Hz로 기록한다. 되감기는 그 결과의 재생이고 새 조건에 옛 경로를 재사용하지 않는다.

## 데이터와 실행

- Config: SI 단위 판·구동·입자 조건. validation으로 지원 범위 제한.
- ModalResult: source=FEM, 판 키, 질량 정규화 모드, 주파수, 잔차, 고정 위치.
- Field: source=FEM, config 키, 복소 변위·진폭 격자·실제 주파수.
- Run: source=approximation, 조건 사본·시드·입경·질량·시간 프레임·이동 거리·사용한 FEM 장.
- RecordEntry: 조건과 결과를 복제한 독립 기록. 비교에서는 같은 카메라를 쓰고 기록 고유 조건과 결과를 각각 참조한다.
- JSON: 현재 실험과 최대 20개 명시적 기록. 소스·스키마·수치 배열을 검사한다. 원본 미디어는 재선택해야 한다.
- CSV: 응답은 Hz/m, 입자는 시간·재질군·질량·입경·위치·누적 이동을 SI로 내보낸다.

조건 수정은 계산을 취소하고 Field·ModalResult·Sweep·Run을 무효화한다. 이후 명시적으로 재계산한다. 작업 ID와 조건 키가 오래된 Worker 응답을 차단한다. 고유치·스윕·입자 적분은 Worker에서 수행하며 취소 시 Worker를 종료한다. 프레임의 시각적 0.5 Hz 진동은 실험의 고주파 시간과 분리하며 배율을 표시한다.

## 관찰·분석 도구

- 재질 / 복소 변위의 정지 위상 / 진폭 / 속도 진폭 / 가속도 진폭.
- 진폭 등고선 30%·65%, 복소 변위 실수부 0. 다중 감쇠 응답에서 이를 엄밀한 영진폭 마디라고 일반화하지 않는다.
- 실제 FEM 요소 경계, 변형된 메시.
- 입자 밀도 16×16 셀, 50개 표본 입자의 시간 궤적, 진폭²의 감소 방향장. 방향장은 공기 흐름이 아니다.
- 재질군별 평균 이동 거리, 좌측 반판 x<Lx/2의 입자 비율, 입자 수와 손실 정책.
- 모드 형상은 최대 1 µm로 정규화한 표시이며 강제응답 수치와 구분한다.
- 고배율 표시는 최대 ±25 mm로 잘라 화면 폭주를 방지한다. 계산 원자료에는 이 제한을 적용하지 않는다.

실제 입자별 클릭 추적, 통계적 분리도·회수율, 임의 ROI, 응력 후처리는 아직 없다.

## 구조·발표

부품별 독립 그룹을 보존한다. 분해·조립 단계·X/Y/Z 절개 위치·부분 절개·투시와 부품 선택을 지원한다. 부품 모델은 개념 구조이며 실제 CAD, 볼트 접촉·공차, 음향 구동기 검증을 대신하지 않는다. 판의 중앙 구멍은 표시용 세부이고 FEM에는 없다. 비중앙/변 지지 조건의 실제 클램프 CAD는 아직 없다.

발표는 같은 결과를 사용하며 출처 칩과 확대 배율을 숨기지 않는다. 종료 시 이전 작업 공간과 레이어·카메라 상태로 복귀한다. 한 개의 사용자 시점 북마크, 전경/수직/접사, PNG 저장을 지원한다. PNG는 현재 3D 캔버스를 최대 DPR 2, 폭 3840px로 렌더하며 UI·실측 중첩을 포함하지 않는다. 영상 녹화는 미구현이다.

## 성능

InstancedMesh, 정지 장면 렌더 생략, DPR 상한 1.5와 저사양 DPR 1, 숨겨진 탭 렌더 생략을 사용한다. 저사양 설정은 계산의 입자 수·결과를 바꾸지 않는다. 메시 4/6/8은 사용자가 고르는 계산 정확도이며 렌더 품질과 분리된다. 실기기 FPS·LOD 자동 선택·GPU 적분·WebGPU는 후속 작업이다.
