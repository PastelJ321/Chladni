# 접촉 입자 모델의 범위

이 모델은 보정된 분리 예측기가 아니다. UI의 접촉·충돌은 주어진 FEM 판 변위에 독립적인 강체 구를 충돌시키는 수치 근사다. 기존 주기 평균 드리프트와 별도로 유지하며 두 모델의 물리적 정확도를 동일하게 표시하지 않는다.

## 실제 계산

- 중력 아래에서 각 입자의 3차원 병진 운동과 구의 각속도를 적분한다. 접촉 시 판의 국소 법선과 순간 수직 속도를 사용한다.
- 법선 충격은 반발계수 e를 사용한다. 접선 충격은 Coulomb 상한 μJn과 고체 구의 유효 질량 m/(1+mr²/I)=2m/7 중 작은 값으로 제한한다. I=2mr²/5다. 미끄럼을 없앨 수 있으면 접촉점의 구름 조건으로 전환한다.
- 정지 접촉은 중력의 접선 성분과 반복적인 법선/마찰 충격을 통해 경사면 아래로 구른다. 별도의 마디/배 방향 힘을 넣지 않는다.
- 정지 공기 Stokes 항력은 선택 사항이며 저 Reynolds 수 구형 입자의 완화 근사다. 공기 속도장·음향 streaming·공기 압력·상호 항력은 계산하지 않는다.
- 복소 FEM 응답을 주어진 판 운동으로 사용한다. 스윕은 33개 준정상 응답을 보간하며 위상은 선형 chirp 주파수를 적분한다. 충돌에 쓰는 판 속도에는 변하는 복소 진폭의 시간 미분도 포함한다. 판 자체의 과도응답 해석은 아니다.

기본 적분은 한 주기당 최소 32 표본 및 최소 480 Hz 중 작은 시간 간격이다. 직접 적분 입자 수를 자동으로 줄이지 않고 계산 예산을 초과하면 거부한다. 내부 검증에서는 64·128 표본으로 시간 간격 수렴을 비교한다. 위치·수평 누적 거리·순간 판 표면에서의 공중 간격을 Float32로 기록한다. 수평 이동 없이 도약만 한 입자도 이동 입자 수에 포함한다.

충격 소산은 충돌 순간 판 정지 좌표계에서 병진+회전 운동에너지의 감소량이다. 판이 움직이면 실험실 좌표계 입자 에너지는 구동부에서 공급받아 증가할 수 있다. 낮은 접근 속도 `max(0.001 m/s, 2gΔt)` 아래에서는 반발을 0으로 놓는 정지 접촉 정규화가 있다. 관통 후 투영을 사용하는 시간 이산화이므로 최대 관통 깊이를 진단으로 남긴다. 이 깊이가 크면 더 작은 Δt의 별도 수렴 검증이 필요하다.

## 물성과 한계

반발·마찰은 물질 이름만으로 검증된 값이 아니다. 표면 수분·충돌 속도·판 상태의 영향을 측정해야 한다. 질량이 다른 독립 구라도 공기 항력이 없으면 충격의 단위질량 운동에서 질량이 상쇄된다. 밀도는 질량 통계와 선택적인 공기 완화 시간에 영향을 준다. 형상 계수는 항력 시간의 근사에만 들어가며 실제 소금 결정이나 녹차 섬유의 접촉 기하를 해석하지 않는다.

입자 간 충돌·겹침 해소·집적 압력·구름 저항·부착/응집·파쇄는 없다. 판 경계는 손실 대신 반사를 사용한다. 프로필에 기록된 정적인 장비 기울기는 아직 중력 좌표에 연결되지 않는다. 현재 프레임의 공중 간격은 실제 수백 Hz 판 운동에 대한 상대량이며, 렌더링에서 선택한 느린 위상과 결합한 화면을 절대 궤적의 고속 촬영이라고 해석하지 않는다.

수직 진동판 위 도약·소산 충돌의 실험/이론 맥락은 [Dynamics of the bouncing ball](https://arxiv.org/abs/1405.3482)을 참고했다. 이 구현은 그 논문의 전체 실험이나 혼돈 통계를 재현·검증한 것이 아니다. 역 클라드니는 공기 유동만으로 생기는 현상이라고 단정하지 않는다. [van Gerner 외, Phys. Rev. E 82, 012301](https://journals.aps.org/pre/abstract/10.1103/PhysRevE.82.012301)은 공기 없이 구름으로 생기는 역 패턴을 다룬다. 그 연구가 본 모델의 실제 혼합물 분리 정확도를 입증하는 것은 아니다.

## 수치 검증

`node --import tsx --test tests/contact.test.ts`에서 다음을 확인한다.

1. 법선 반발과 Coulomb 제한, 고체 구의 2/7 접선 충격의 폐형식과 일치.
2. 임의 방향 충격 200개가 순간 판 정지 좌표계의 운동에너지를 생성하지 않음.
3. 정지 수평판에서 수평 이동·도약 없음, 동일 시드 기록 재현, 수 보존·유한성.
4. 공간적으로 균일한 진동판에서 실제 도약을 계산하되 수평 패턴을 만들지 않음.
5. 정적인 경사면에서 중력에 의한 구름 거리가 해석 가속도 5g sinθ/7의 8% 이내.
6. 32/64/128 표본의 진동 접촉 계산에서 64→128 차이가 32→128 차이보다 작고, 검증한 입력의 공중 간격 RMS 차이가 0.2 mm 미만.
7. 계산 예산 초과와 손상된 처방 진동장 거부.

이 검증의 진동장은 명시적인 합성 수치 fixture다. 실제 연구 관찰 데이터나 실험 장치의 정확도 검증으로 보고하지 않는다.
