# v0.3 코드 개편 기록

2026-11-16 · 대상: 기존 체크아웃과 사용자 지정 `codex/chladni-v0.2` 브랜치. 새 복제본·워크트리·버전 폴더는 만들지 않았다.

## 기준과 감사

v0.2 커밋 `463a6a0`의 소스·테스트·문서와 현재 로컬 상태를 기준으로 검토했다. 빈 작업 트리에서 시작했으며 기존 solver·연구 원자료를 보존한다. 범용 공학 설정을 늘리는 대신 입경·주파수 반복 실험에 기본 화면을 맞춘다.

| 대상                             | 판단과 변경                                                                |
| -------------------------------- | -------------------------------------------------------------------------- |
| `solver/` BFS·모달·응답·Worker   | 유지. 검증된 수치 구현을 UI 개편과 분리                                    |
| `experiment/useExperiment`       | 공통 세션·취소·조건 키·기록 상태 유지                                      |
| 공통 입경 `Grains`               | 독립 sand/salt 그룹 추가. v0.2 필드는 읽기 호환용으로 보존                 |
| `simulation/particles`           | 군별 입경·밀도·마찰·형태를 초기 표본과 동적 이동에 적용                    |
| 6개 workspace 및 `AnalysisPanel` | 3개 공간과 작업별 도구로 재구성. 불필요한 패널·CSS 제거                    |
| `App`                            | 세션 조정·내보내기·3개 공간 조합. 미디어·분석·연출 UI는 전용 모듈로 분리   |
| 단일 분해 Y 오프셋               | 부품별 시간차·회전·해제 순서·복귀 pose로 교체                              |
| `CameraRig / LabRenderer`        | 독립 director의 결과만 표시. 수동 조작 인계, 좁은 비교 공간 카메라 보정    |
| 장비 procedural geometry         | 와셔·볼트·프레임·코일·콘·고무를 독립 재질과 그룹으로 개선                  |
| IO                               | 새 schema3 쓰기, schema2/3 읽기, 저장 결과를 임의 재계산하지 않음          |
| 테스트                           | 기존 수치 19개 유지·갱신, v0.3 상태 8개 추가. 이전 UI 테스트는 legacy 보관 |

## 모듈 경계

```text
experiment/config,types,useExperiment   조건 · 유효성 · 공통 세션
solver/* → Worker                     판 FEM · 고유모드 · 응답 · 스윕
simulation/particles                  시드 표본 · 동적 적분 · 결과 재생
analysis/metrics, io/session           측정 · 기록 · CSV/JSON
scene/instrument,materials,parts       기구 그룹 · PBR · 연결/출처
scene/assetContract                    향후 GLB/CAD의 노드·단위·출처 계약
animation/director,useDirector         연출 전용 시간과 샘플링
render/CameraRig,LabRenderer,layers     카메라 · Three.js · 데이터 표시
ui/*                                  실험 · 분석 · 구조 · 미디어 · 연출 도구
```

Director는 Config/Run을 입력으로 받아 변경하지 않는다. 결과 진행률과 표시 pose만 반환하고 렌더 경계에서 기존 계산장을 참조한다. 수동 조작 시 카메라가 인계되어 후속 프레임이 사용자 이동을 덮어쓰지 않는다. Run 결과 시간은 연출 재생 중에도 별도 유지한다.

## 실물 모델 교체 준비

`InstrumentAssetManifest`는 출처 종류, 참조 자료, metersPerUnit, 필수 부품의 고유 노드 이름을 요구한다. `bindInstrumentAsset`는 누락·중복 매핑을 거부한다. 판·와셔·볼트·연결부·구동부·지지를 별도로 연결할 수 있다. 이 코드는 교체 계약이며 GLB 파일 업로드·스케일 변환·자동 CAD 정합이 완성됐다는 뜻은 아니다.

현재 모델은 기본 중앙 구동 기구의 개념 표현이다. 실제 사진·규격은 제공되지 않았다. 다른 경계 조건의 실제 클램프, 치수 변경에 따른 전 체결 기구 재설계, 공차·접촉 해석은 구현하지 않았다. 계산판의 치수 변경과 실제 장비 CAD 변경을 혼동하지 않는다.

## 저장 호환성과 출처

v0.2 `groups` 없는 조건은 기존 평균·편차·각 밀도·공통 마찰을 읽는다. 저장 기록의 JSON key를 바꾸는 강제 migration은 없다. v0.3에서 군을 편집할 때만 독립 그룹을 생성한다. 결과 배열과 구버전 기록은 read/write 왕복 검증을 추가했다. 원본 미디어·관측 메타데이터·연출 상태는 JSON에 넣지 않는다.

FEM 결과, 비보정 입자 근사, 사용자 실측 미디어, 개념 기구가 화면에서 구별된다. 교육용 코사인/역 개념 예제는 `concept/`와 legacy 테스트에만 보존하며 실험 계산 경로에서 쓰지 않는다.

## 후속 작업

1. 실제 체 선별 입경·마찰 측정과 반복 실험으로 이동 계수 보정. 공기장·접촉 모델 없이는 역 클라드니 예측을 추가하지 않는다.
2. 실물 사진/CAD·체결 치수와 구동부 전달함수 확보. 중앙 체결 패치와 장치 연성 모델의 실측 검증.
3. 영상 네 모서리 지정·원근 보정, 주파수/시간/입경 메타데이터 저장, 패턴 정합 지표.
4. GLB 로더와 실제 부품 자산 연결, 절단면 캡, 임의 ROI·개별 입자 추적.
5. 실제 모바일 GPU·Safari/Firefox 성능과 키보드/보조기기 검증. 영상 녹화와 물리적 DOF는 미구현.

실행 결과는 [검증 기록](VALIDATION.md), 화면과 조작은 [설계](DESIGN.md)에 있다.
