# Chladni — 설계 및 구현 명세

2026-11-12 · QuadraJ · v0.1 초안

## 1. 아트 디렉션과 디자인 원칙

관찰 대상은 금속판과 그 위의 입자다. 장면은 어두운 촬영 스튜디오에 놓인 실제 장비처럼 구성한다. 구조를 설명할 때에만 부품 간격, 투명도, 색, 변위 배율을 바꾼다. 각 연출은 장면에서 읽어야 할 물리적 관계에 대응한다.

세 가지 중심을 둔다.

| 방향                     | 화면에서의 구현                                       | 판단 기준                         |
| ------------------------ | ----------------------------------------------------- | --------------------------------- |
| Research Instrument      | 일정한 단위, 모드별 조건, 작은 응답계, 모델 출처      | 계측값과 예시값이 혼동되지 않는가 |
| Product Showcase         | 브러시드 알루미늄, 가공 금속, 무광 콘, 낮은 반사 바닥 | 조명을 꺼도 재질의 차이가 남는가  |
| Scientific Visualization | 같은 장에서 나온 변위·마디선·입자·방향장              | 정보 레이어가 서로 일치하는가     |

Glass는 카메라 도구·하단 타임라인·발표 컨트롤·라벨에만 쓴다. 좌우 패널은 평탄하고 조용한 배경을 사용한다. 장비, 바닥, 배경에는 유리나 발광 셰이더를 쓰지 않는다. 블룸, 색수차, 무지개 팔레트, 스캔 라인, 홀로그램은 사용하지 않는다.

시각적 품질은 조명 방향, 부품의 접촉, 그림자, 하이라이트의 폭에서 만든다. 접사에서 보이는 볼트의 육각 머리와 나사산, 구동부의 코일과 자석, 표면 입자의 불규칙한 형상이 장면을 지탱해야 한다.

## 2. 화면 정보 구조와 UX 흐름

### 데스크톱

```text
QuadraJ / Chladni     장비 탐색 · 현상 분석 · 실험 비교     모델 안내 · 데모
─────────────────────────────────────────────────────────────────────────
뷰 목록              메인 3D 장면                          조건 / 구조·레이어
                      현재 뷰 제목                          모드 선택
                      해석 모델 표시                        주파수 / 응답
                      장비와 현상                           구동 세기 / 입자
                      주석 · 범례                           비교 조건
                      전경 / 수직 / 접사 / PNG              레이어
─────────────────────────────────────────────────────────────────────────
재생 · 초기화 · 시간       타임라인 스크러버          속도 · 조건 저장
```

세 작업 공간의 조건은 유지된다. 사용자가 현상 분석으로 갔다가 전경으로 돌아와도 재질, 주파수, 시간, 레이어는 그대로다. 뷰 전환에서는 카메라만 목적에 맞게 이동하고, 조립·인과 설명처럼 시작 상태가 필요한 뷰는 시간을 0으로 맞춘다.

첫 화면은 이미 형성된 패턴을 보여준다. 로딩이 끝나면 2.2초에 걸쳐 노출을 올리며 장비를 드러낸다. 자동 회전은 하지 않는다. 짧은 설명과 직접 조작 가능한 장면이 먼저 보인다.

### 발표 흐름

`데모 재생 → 전경 → 분해 → 조립 → 진동 전달 → 진동 확대 → 입자 궤적 → 접사`

데모에서는 좌우 패널과 하단 연구 컨트롤을 숨기고 최소한의 제목과 장면 이동 컨트롤을 남긴다. 발표자는 중지·다음 장면·종료를 직접 제어한다. 수동 전체 화면은 브라우저 Fullscreen API를 사용하며 지원되지 않는 환경에서는 화면 내 발표 모드를 쓴다.

### 탐색·분석 흐름

`장비 선택 → 구조 확인 → 모드 선택 → 주파수/세기 조절 → 시간 재생 → 레이어 확인 → 조건 저장`

주파수는 선택한 근사 모드의 응답을 바꾼다. 모드 자체는 명시적으로 선택한다. 현재 구현은 실제 장비 주파수 스윕에서 모드를 자동 식별하지 않는다.

### 비교 흐름

`실험 비교 → 모드 비교 / 실험 기록 / 역 패턴 → 조건 설정 → 분할 위치 조절`

이미지·영상은 Object URL로 로컬에서 연다. 실제 기록이 없으면 빈 자리에 불러오기 버튼을 보여준다. 생성한 이미지나 데모 이미지를 실제 실험으로 표시하지 않는다. 실측 주파수는 기록 메타데이터로 입력하며 모델 주파수와 별도로 유지한다.

### 모바일

3D와 타임라인을 유지한다. 화면 하단의 `뷰`, `설정` 버튼으로 한 번에 한 패널만 연다. 패널은 닫기 버튼으로 바로 닫을 수 있다. 두 비교 장면의 크기가 작아지므로 정밀 비교는 넓은 화면이 적합하다.

주파수 비교는 독립적인 근사 모드 두 개를 비교한다. 두 장면의 좌표계·카메라는 같다. 직접·역 패턴 비교에서 역방향 이동은 유체·공기 효과를 푼 결과가 아니다. 방향장은 입자 이동 모형의 기울기이며 공기 속도장이 아니다.

단면과 부분 절개는 GPU 클리핑으로 구현했다. 잘린 면을 재구성한 CAD 단면 캡·해칭은 후속 작업이다. 구동부 재질은 구분되지만 실제 제품의 CAD나 제조 상세를 복제한 모델은 아니다.

## 4. 3D 장면·구조·재질·조명

### 장치 구조

판 300 × 300 × 2 mm, M6 체결은 **설계 가정**이다. 실제 실험 장비를 측정한 값이 아니다. 장면의 3.6 단위가 300 mm에 해당하며, 입자의 가시성·볼트 나사산 등 미세 요소는 화면에서 읽히게 조정했다.

```text
입자
육각 볼트 / 상부 와셔
알루미늄판 (가장자리 자유)
하부 와셔 / 전달봉 체결부
전달봉
가동 어댑터 ─ 코일 포머 ─ 콘 / 서라운드
보이스 코일 ↔ 고정 자석·폴 피스
고정 바스켓
베이스 / 방진 발
```

판 가장자리를 지지하는 가짜 기둥을 넣지 않는다. 베이스는 자석·바스켓만 받친다. 고정된 자석과 움직이는 코일을 분리한다. 전달봉은 콘의 장식 캡이 아니라 코일 포머에 이어지는 강성 어댑터에 연결한다. 전원 터미널과 케이블은 고정부 옆에 배치한다.

지금의 스피커 조립은 기구 관계를 설명하는 모델이다. 접착층·코일 갭 공차·코일의 허용 변위·서스펜션 강성·판 질량과 구동부의 정합은 제조 설계로 검증되지 않았다. 실물 제작용 도면으로 쓰지 않는다.

| ----------- | --------------------------------------------------- | --------------------------------------- |

| 콘          | #343936 · .05 / .83                                 | 종이 복합재처럼 확산 반사, 양면         |

입자는 자연색을 유지한다. 혼합 입자의 색은 규사와 소금을 구분하지만 실제 입경별 분리의 실험 결과를 뜻하지 않는다. 이동성 계수 1.00 / 0.72는 정성적 차이를 보여주는 예시다.

### 조명과 렌더링

- 차콜 배경과 거친 무광 바닥. 반사 바닥·유리 무대 없음.
- 왼쪽 위 따뜻한 키라이트, 반대쪽 저채도 차가운 필라이트.
- 네 개의 스튜디오 반사판을 PMREM으로 변환해 판과 봉에 긴 하이라이트 형성.
- 1024² VSM shadow와 분산 블러, 낮춘 그림자 강도로 금속·바닥 접촉 유지.
- Linear 작업 공간 → ACES filmic → sRGB 출력. 색 텍스처와 데이터 텍스처를 구분.
- 그림자·주변 조명·바닥이 부품을 받치고, 발광으로 윤곽을 대신하지 않음.

### 카메라

33° 수직 시야각을 기본으로 원근 과장을 줄인다. 전경은 위에서 비스듬히 내려다보며 판과 구동부가 함께 보인다. 수직 시점은 패턴 분석에 사용한다. 접사는 판과 입자·볼트에 집중한다. 뷰 전환은 위치와 타깃을 감쇠 보간하며, 사용자가 드래그하면 자동 이동을 중단한다. 초기 reveal 외에 카메라가 계속 떠다니지 않는다.

`prefers-reduced-motion` 환경에서는 초기 노출 변화·카메라 전환·미세 입자 도약을 줄인다. 사용자가 명시적으로 실행한 타임라인과 진동 설명은 계속 사용할 수 있다.

## 5. UI 스타일 가이드

| 요소    | 규칙                                                     |
| ------- | -------------------------------------------------------- |
| 배경    | #151a18, 거의 중성인 흑연 계열                           |
| 본문    | #dce2db, 보조 #919b92                                    |
| UI 선택 | 저채도 세이지, 작은 면적에만                             |
| 데이터  | 청록 #709d9d ↔ 모래색 #d9ba87, 진폭 0→1 범례             |
| 서체    | IBM Plex Sans KR, 장면 영문 제목 Georgia, 수치 monospace |
| 반경    | 버튼 4–5px, 도구 8px, 타임라인 10px                      |
| 구분선  | 흰색 약 7% 또는 세이지 약 15%                            |
| 크기    | 조작부 10–12px 중심. 보조 캡션은 작게, 입력 수치는 크게  |
| 간격    | 4 / 8 / 12 / 16 / 24 / 32px 리듬                         |

유리 표현은 한 겹의 경계선과 위쪽의 약한 흰색 하이라이트, 아래쪽의 어두운 엣지, 낮은 채도의 뒤 배경 블러로 두께를 암시한다. 강한 번쩍임·색 번짐을 추가하지 않는다. Glass 안에 Glass를 중첩하지 않는다. 현재 CSS 표현은 굴절을 물리적으로 계산하는 렌즈가 아니며, 배경 대비가 낮을 때도 읽히도록 불투명 성분을 남긴다.

표시는 한국어, 장면의 학술적 뷰 이름은 영어를 병기한다. 문장은 조작과 해석에 필요한 것만 남긴다. 기능 구현 방식·팀의 의도·비전 문구를 제품 화면에 늘어놓지 않는다. 모델 상세는 별도 대화상자로 이동한다.

| 주파수 조절 | 선택 모드의 상대 응답 변경                               | 응답계와 이동 정도                  |
| 세기 조절   | 시각적 구동 세기 변경                                    | 변위 과장과 입자 진행량             |
| 시간 스크럽 | 결정적 경로의 해당 프레임 보간                           | 앞뒤로 같은 입자 위치 재현          |
| 재생        | 시각화 시간 증가                                         | 끝에서 정지, 다시 재생하면 처음부터 |
| 단계 클릭   | 인과 구간으로 점프                                       | 현재 단계의 밑줄                    |
| 분할 조절   | 두 뷰포트 비율 변경                                      | 동일 카메라, 각 패널 안에 장비 맞춤 |
| PNG 저장    | 현재 3D 캔버스 다운로드                                  | 완료 토스트                         |
| 조건 저장   | 모델 종류·비보정 상태·조건·기록 메타데이터 JSON 다운로드 | 완료 토스트                         |
| 전체 화면   | 브라우저 화면 확장 / 복귀                                | 최소 발표 컨트롤                    |

오류는 구체적인 복구 행동을 제시한다. WebGL 초기화 실패·컨텍스트 손실은 새로고침 또는 다른 브라우저 안내, 파일 형식·크기 오류는 허용 형식·250 MB 한도를 표시한다. 분석 결과나 업로드 성공을 꾸며내지 않는다.

키보드는 Space, C, R, 방향키, Esc를 지원한다. 입력 필드·버튼·모달에 포커스가 있으면 전역 단축키가 입력을 가로채지 않는다. 모달은 native dialog로 포커스를 가둔다. 슬라이더·토글·파일 입력에는 접근 가능한 이름을 준다. 3D 부품 선택에는 동일한 기능의 DOM 목록이 있다.

`SceneState`는 뷰·모드·주파수·세기·시간·부품·레이어·비교·카메라를 묶는다. 모델 계산은 DOM이나 Three.js에 의존하지 않는다. UI는 상태만 변경하고, 렌더러는 상태를 읽어 geometry·material·camera를 갱신한다.

### 물리적 해석의 경계

코사인 중첩 장은 시각적 근사 기저이며 중앙 체결·자유 가장자리 판의 고유방정식 해가 아니다. 중앙에서 0인 상대 형상을 보이는 것은 중앙 구동점의 절대변위나 해당 모드의 구동 가능성을 입증하지 않는다. 특히 이상적인 점 구동과 반대칭 모드의 결합 강도는 별도의 경계조건 해석이 필요하다. 실제 장치의 대칭성·구동 편심·체결 패치·감쇠를 이 근사식으로 추론하지 않는다.

정상 입자의 이동은 φ²를 줄이는 방향이다. 모델의 경로는 재료 법칙에서 유도한 시간이 아니다. 입자 궤적을 미리 81프레임 계산해 저장하고, 시간에 따라 보간한다. 동일 시드의 초기 배치를 공유하므로 조건 비교와 역 스크럽이 재현된다. 역 패턴은 φ²를 증가시키는 안정적인 작은 단계로 이동한다.

### 성능과 자원

- 입자는 7,200개 InstancedMesh, 불필요한 개별 Mesh 없음.
- 입자 경로는 모드·재질·직접/역 조건별 캐시.
- 등고선·방향장은 모드나 표시 설정이 바뀔 때 재생성.
- 기기 픽셀 비율 상한 1.8, ResizeObserver로 화면 대응.
- 숨겨진 탭에서 애니메이션과 시각화 시간 정지.
- renderer·geometry·material·texture·Object URL 정리.
- 두 조건 비교는 단일 WebGL 컨텍스트의 viewport/scissor 렌더링.

CPU에서 입자 인스턴스와 판 변형을 업데이트한다. 저성능 기기용 LOD, GPU 입자 업데이트, Worker, 수동 품질 선택은 아직 구현하지 않았다. 실측 FPS 기준을 통과했다고 주장하지 않는다. WebGL 2 기준이며 WebGPU 전환은 별도 백엔드와 노드 재질 도입이 필요하다.

### 실제 연구 데이터로 확장

1. 실물 치수, 재료의 E·ν·ρ, 체결 반경과 토크, 구동부와 봉의 질량·강성·감쇠 기록.
2. 동일 장비의 주파수 스윕, 입력 전압, 판의 가속도/레이저 변위, 촬영 시점 동기화.
3. 중앙 체결 패치와 자유 가장자리 조건을 적용한 plate/shell FEM. 모드 형상과 구동점 참여계수 검증.
4. 모델 파일에 `source`, `units`, `boundaryConditions`, `normalization`, `calibrationVersion` 포함.
5. 촬영 보정·판 모서리 정합·입자 추적. 이미지 마디선과 FEM 마디선 오차를 비교.
6. 입경·밀도·형상별 실험. 마찰·충돌·공기/유체 효과가 필요하면 DEM/유동 모델과 결합.
7. 실제 관측 범위 안에서만 분리율·회수율·불확도를 표시. 현재 초안에는 이 지표가 없다.

## 8. 실행 가능한 코드 초안

코드가 저장소에 구현되어 있다. `npm run dev`로 직접 탐색할 수 있고 `npm run build`로 정적 배포 파일을 만든다. 외부 모델·HDRI·데모 사진을 가져오지 않으므로 최초 실행 후의 장면에는 원격 자산 요청이 없다.

대표 계산식은 `physics.ts`에 있다.

```ts
// x, z ∈ [-1, 1]. Calibrated eigenmodes are not implied.
const a = ((x + 1) * Math.PI) / 2;
const b = ((z + 1) * Math.PI) / 2;
const phi = (Math.cos(m * a) * Math.cos(n * b) - Math.cos(n * a) * Math.cos(m * b)) / 2;
```

실제 모드 데이터를 붙일 때 이 계층을 교체하고 UI·부품·발표 기능은 유지할 수 있다. 유한요소 결과는 정규화된 판 좌표에서 변위장을 조회하는 인터페이스로 연결하는 것이 다음 단계다. 현재 이 교체 인터페이스와 파일 파서는 구현하지 않았다.

## 9. 발표 데모 시퀀스

총 58초. 프레젠테이션은 버튼으로 시작하며 자동 실행되지 않는다.

| 시간  | 장면                 | 발표 포인트                                    |
| ----- | -------------------- | ---------------------------------------------- |
| 00–07 | Hero                 | 판, 중앙 구동부, 자연색 입자를 함께 소개       |
| 07–14 | Exploded             | 판 가장자리가 자유롭고 중앙 축이 연결됨을 확인 |
| 14–26 | Assembly             | 지지 구조 → 구동부 → 전달봉 → 판 → 볼트 순서   |
| 26–33 | Mechanism            | 코일에서 판으로 이어지는 축 방향 경로          |
| 33–41 | Motion amplification | 실제 진폭이 아닌 과장된 상대변위, 마디와 배    |
| 41–51 | Particle trace       | 입자가 작은 진폭 영역으로 모이는 경향          |
| 51–58 | Macro                | 입자와 금속 표면을 가까이서 관찰               |

스페이스로 일시정지하고 `다음`으로 장면을 넘긴다. 수동 종료 시 데모 직전의 실험 조건으로 복귀한다. 종료 후에는 장비 전경으로 돌아간다. 조용한 발표 환경을 위해 오디오를 자동 재생하지 않는다. 기본 카메라와 PNG 저장으로 대표 이미지를 뽑을 수 있다.

실제 기록을 사용할 발표에서는 58초 데모 뒤 `실험 비교 → 실제 실험 vs 모델`로 이동해 촬영 조건과 모델 가정을 설명한다. 비보정 상태에서 모델의 Hz와 실측 Hz가 일치한다고 말하지 않는다.

## 10. QuadraJ 공개용 문구 초안

**제목**: Chladni

**목록 설명**: 진동판의 구조와 클라드니 패턴, 입자의 이동을 탐색하는 인터랙티브 3D 시각화.

**프로젝트 소개**:

금속판 위에 흩어진 입자는 진동이 작은 영역에 모여 패턴을 드러낸다. Chladni에서는 장비를 분해해 연결 구조를 살펴보고, 모드와 진폭 분포를 바꾸며 입자의 이동을 따라갈 수 있다. 직접 촬영한 실험 기록을 불러와 모델과 나란히 비교할 수도 있다.

현재 시각화는 현상을 설명하기 위한 해석 모형을 사용한다. 표시된 주파수와 입자 이동은 실제 장비의 계측·보정 결과가 아니다.

**버튼**: 시각화 열기

**대표 이미지 대체 텍스트**: 중앙 구동부 위의 알루미늄 사각판과 마디선을 따라 모인 모래 입자.

**태그**: Interactive · Scientific visualization · Three.js
