# Chladni v0.3 — 실험에 집중한 구성

2026-11-16. 연구 주제는 입경 통제와 구동 주파수에 따른 직접·역 클라드니 혼합 입자 분리다. 현재 계산 범위는 판 FEM과 직접 패턴 방향의 입자 이동 근사이며 역 현상은 실측 비교 대상으로 남긴다.

## 화면과 조작

| 작업 공간 | 기본 조작                                                         | 필요할 때 열기                                              |
| --------- | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| 실험      | 구동 주파수, 스윕 범위, 독립 규사/소금 입경, 계산 실행            | 구동 세부, 밀도·마찰·형태, 초기 배치·시드, 판·FEM 고급 설정 |
| 분석      | 주파수 응답, 고유모드, 진폭·등고선·궤적·밀도, 초기/최종·기록 비교 | 속도/가속도·메시·기울기 레이어, 실측 미디어·CSV             |
| 장치      | 부품 선택, 분해·조립, 부분 절개, XYZ 단면, 투시                   | 부품 연결 정보                                              |

공통 상단에는 실험 기록, 장면 연출, 저장·도구만 둔다. 하단 실험 시간과 별도로 연출 시간 도구를 제공한다. 모든 작업 공간은 동일 Config·ModalResult·Field·Run을 유지한다. 기본 화면에서 FEM 메시와 재료 상수는 접혀 있다.

왼쪽 294px 설정과 넓은 3D 공간을 사용한다. 우측 고정 패널은 없으며 설정 자체를 접을 수 있다. 모바일 설정은 서랍으로 열고 닫는다. 발표 도구는 화면 장식을 최소화하면서 출처·확대 배율·종료 조작을 남긴다. Escape는 연출·발표·설정 서랍을 닫는다. 입력 중이 아닐 때 Space는 연출 또는 결과 재생을 전환한다.

## 디자인 시스템

- 외곽: 실버와 웜그레이 `#eeede9 / #e3e7e8`. 실험 공간: 중성 차콜, 작업대·바닥·그림자로 깊이 유지.
- 텍스트: IBM Plex Sans KR, 주요 입력 12–13px, 작은 보조 문구 11–12px, 주파수 수치 45px. 장식 영문·이탤릭 세리프·이니셜 로고 없음.
- 데이터: 낮은 채도의 청회색과 모래색. 재질군의 색상은 규사/소금과 일관되게 대응.
- Glass: 카메라 바, 연출 타임라인, 부품 팝오버 등에만 적용. 가장자리 밝기, 내부 음영, 복수 하이라이트와 섬세한 배경 블러를 함께 사용한다. 블러 미지원 환경에는 불투명 대체 스타일을 쓴다. 광학적 굴절을 계산하는 셰이더는 아니다.
- 조명: 3개 중성 라이트 카드로 PMREM 반사 환경 구성, 따뜻한 키와 차가운 필, 부드러운 그림자. 빛나는 장비·색수차·네온 없음.
- 금속: 약한 방향성 브러시와 거칠기 변화, 알루미늄·스틸·구리 분리. 스피커 콘·고무·프레임을 서로 다른 재질로 유지.
- 입자: 규사는 불규칙 다면체, 소금은 각진 결정 근사, 각 입자의 실제 입경·비균일 크기·방향을 InstancedMesh로 표현. 작은 입자가 전경에서 미세하게 보이는 것은 크기를 유지한 결과다.

## 계산·데이터

판 FEM 및 스윕 솔버는 v0.2 구현을 유지한다. BFS 요소, 경계 조건, 모달 하중, 감쇠 및 기준식은 [v0.2 모델 문서](archive/DESIGN-v02.md)에 있다. 300×300×2 mm는 기본 설계값이며 중앙 절점 구속은 실제 체결 패치의 정밀 모델이 아니다.

`grains.groups.sand / salt`에 평균 입경·분포 폭·밀도·마찰·형태·체 구간을 독립 저장한다. 입경은 균등분포 `d = mean × (1 ± spread)`이며 상한/하한을 UI에 표시한다. 명목 체 구간은 125–250 / 250–355 / 355–500 / 500–710 / 710–1000 µm다. 실제 체눈 표준이나 통과·잔류 입경 실측으로 간주하지 않는다.

입자별 질량·완화 시간·이동성에 각 군의 물성을 사용한다. 같은 시드에서 한 군의 조건만 바꾸면 다른 군의 초기 표본과 물성은 그대로다. 입자 간 상호작용이 없으므로 다른 군의 궤적도 변하지 않는다. 이는 모델의 독립성이지 혼합물 상호작용의 검증이 아니다.

입자 적분은 경험적인 판 가속도 구배 기반 이동과 선형 항력 완화를 사용한다. 분리를 강제하지 않으며 무구동 또는 이동 임계 아래에서는 이동이 생기지 않는다. 직접/역 선택 스위치로 반대 방향 경로를 만들지 않는다. 실측, FEM, 입자 근사, 개념 기구의 출처를 분리한다.

조건 변경은 계산을 무효화하고 재계산을 요구한다. `chladni/2`의 공통 입경은 두 군의 기본값으로 해석하되 원본 Config를 변형하지 않는다. 새 설정에서만 독립 값을 기록한다. 기록의 조건 키·모드·FEM 장·입자 배열은 JSON 왕복에서 그대로 보존한다. 결과의 원본은 데이터 모델이며 Three.js 객체가 아니다.

## 통합된 관찰 도구

- 모드·강제응답: 계산된 고유모드와 선택 주파수 응답을 구별하고, 모드는 최대 1 µm 정규화 표기.
- 진폭·변위·속도·가속도: 동일 FEM 장에서 파생. 응력은 제공하지 않는다.
- 등고선: 복소 변위 실수부 0 및 진폭 30%·65%. 감쇠된 복소 응답의 모든 0선을 엄밀한 영진폭 마디로 해석하지 않는다.
- 궤적: 판 전체·중앙·좌측·우측 영역에 속한 표본 입자의 저장 궤적. 임의 ROI나 개별 클릭 추적은 후속 범위.
- 밀도: 16×16 공간 격자. 이동량과 좌측 반판 비율은 통계이지 실제 분리 효율이 아니다.
- 비교: 초기/최종 또는 독립 기록의 각 조건·결과를 같은 카메라로 표시한다. 실측 미디어를 열면 사진/영상 비교를 우선한다. 원근 미보정이며 사진을 FEM 값으로 변환하지 않는다.
- 구조: 부품별 그룹과 연결 메타데이터, 분해 단계, XYZ 절개 평면, 외형 투시. 중앙 구멍·나사산은 렌더링 세부이며 FEM에는 포함하지 않는다. 절단면 캡은 없다.

## 장면 연출

| 시퀀스         | 시간 | 연출과 데이터 연결                                                                          |
| -------------- | ---: | ------------------------------------------------------------------------------------------- |
| 장비 전경      |  9 s | 무게감 있는 전경 이동 후 정지, 금속과 구동 구조 관찰                                        |
| 정밀 분해·조립 | 18 s | 볼트 회전·축 해제 → 상부 와셔 → 판 → 하부 와셔·연결부 → 구동부 분해. 중간 정지 후 역순 복귀 |
| 공진과 모드    | 12 s | 선택한 FEM 응답의 변위 확대, 진폭 분포에서 등고선으로 전환, 수직 카메라                     |
| 입자 이동 관찰 | 14 s | 저장된 Run의 처음부터 끝까지 재생, 매크로 전환과 영역·표본 궤적 강조                        |
| 실측과 비교    | 10 s | 수직 관찰로 전환, 저장 결과와 사용자 영상의 시간 오프셋을 맞춰 나란히 표시                  |

독립 `AnimationDirector`가 카메라 위치·타깃·up·FOV·초점 거리, 부품 이동/회전, 레이어, 표시 배율과 결과 재생 진행률을 샘플링한다. 초점 거리는 카메라 속성으로만 반영하고 광학 DOF는 렌더하지 않는다. quintic ease와 시간차를 사용하며 탄성 바운스는 없다. 계산과 연출 시간이 독립적이다. 실제 초고주파를 브라우저 프레임으로 재현하는 연출이 아니다.

직접 조작은 자동 카메라와 연출 진행을 즉시 중단한다. 일시정지는 현재 장면을 유지한다. 연출 정지 시 레이어와 부품은 원래 탐색 상태로 돌아오며 자동 카메라가 살아 있었다면 시작 시점을 복원한다. 직접 조작 후에는 사용자 시점을 유지한다. 새 시퀀스를 선택하면 현재 시점에서 전환한다. PNG는 3D만 최대 DPR 2·폭 3840px로 저장하며 UI와 실측 중첩은 포함하지 않는다.

## 공개용 설명 초안

Chladni는 입경과 주파수를 바꾸며 혼합 입자의 움직임을 관찰하는 가상실험실입니다. 판의 진동 계산, 입자 이동 근사, 실제 촬영 기록을 같은 실험 조건으로 비교할 수 있습니다. QuadraJ 제작.
