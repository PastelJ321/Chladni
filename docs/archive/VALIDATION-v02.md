# v0.2 검증 기록

2026-11-12. 실제 실행 결과만 기록한다. GitHub CI의 사용량 한도는 코드 오류와 구분한다.

## 단순지지 기준

Al, 300×300×2 mm, E=69 GPa, ρ=2700 kg/m³, ν=.33. Navier 기준:

`f_mn = π/2 √[Eh²/{12ρ(1−ν²)}] (m²/a²+n²/b²)`

| 메시 |   FEM 1차 Hz |      기준 Hz |  상대 오차 |
| ---- | -----------: | -----------: | ---------: |
| 4×4  | 107.94042625 | 107.92602386 | 0.0133447% |
| 6×6  | 107.92885425 | 107.92602386 | 0.0026225% |
| 8×8  | 107.92691758 | 107.92602386 | 0.0008281% |

24개 보존 모드의 최대 상대 고유치 잔차는 위 세 메시에서 약 1.8e−13 / 2.1e−12 / 1.0e−11이다. 원자료는 `artifacts/v02-validation.json`. 이 사례의 수렴만으로 중앙 체결·스피커·입자 모델의 실물 정확성을 주장하지 않는다.

## 자동 검증 범위

`npm test`: **19개 통과** (교육용 8 + 연구 엔진/상태 11). `npm run build`: TypeScript/Vite 통과. `npm run test:browser`: **3개 시나리오 통과**. 검사 항목:

- Navier 기준과 메시 수렴, 고유치 잔차.
- 두께 2배→주파수 2배, 양 변 2배→1/4, E 4배→2배, ρ 4배→1/2.
- 경계 조건과 고정 위치의 결과 변화, 구동점 참여도와 감쇠.
- 구속점 점 힘은 무응답, 고정부 변위는 비영 응답.
- 스윕 공진 후보, 동적 입자 재현성·보존·유한성·무구동 무이동·입경 차이.
- 시드·직접 뿌리기 초기 배치, 밀도 격자와 구역 집계.
- JSON 조건/결과/활성 실험 왕복, 손상된 모드 배열 거부.
- 33단계 준정상 스윕의 실제 FEM 장 보존.

브라우저 테스트는 새 작업 공간, 실제 Worker 계산, 공진 선택과 입자 적분, 조건 변경 무효화, CSV·JSON, 두 실험 비교, 절개 위치, 발표 복귀, 실측 미디어 출처, 모바일을 검사한다. v0.1의 5개 메뉴 테스트는 `tests/legacy/`에 보존했으며 새 버전의 통과 개수에 포함하지 않는다.

검토 화면은 1512×982 데스크톱과 390×844 모바일, 로컬 Chromium SwiftShader다. `artifacts/v02-*.png`를 실제로 열어 검토한다. 자동 브라우저에서 성공했다고 실제 기기의 60 FPS나 Safari 호환성을 주장하지 않는다.

## 알려진 제한

- 비보정 경험적 입자 모델, 중앙 절점 고정의 격자 의존성, 24모드 절단.
- 점 힘과 질량 가중 RMS를 실제 점 계측 응답과 직접 동일시할 수 없음.
- 선형 이론, 작은 변형, 얇은 균일 판에 한정. 비선형/응력/구동 장치 연성 검증 없음.
- CSV 관측량을 자동 확인하거나 보정하지 않음. 영상 원근 정합·정량 패턴 오차 미구현.
- Three.js 청크가 압축 전 500kB를 약간 넘는 Vite 크기 경고. 빌드 실패가 아님.
- 실제 장비, 실제 실험 데이터, 실기기 GPU 성능 검증은 수행하지 않음.
