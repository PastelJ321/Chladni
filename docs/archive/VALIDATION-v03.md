# v0.3 검증 기록

2026-11-16. 실행한 결과만 기록한다. GitHub CI의 사용량 한도는 코드 오류로 분류하지 않는다.

## 실행 결과

- `npm test`: **27개 통과**. 교육용 개념 8개, 기존 연구 엔진/상태 11개, v0.3 입자군·연출·저장 호환성 8개.
- `npm run build`: TypeScript 및 Vite 통과. Three.js 청크 약 522 kB(압축 전) 크기 경고가 남으며 빌드 실패는 아니다.
- `npm run test:browser`: **4개 시나리오 통과**. 로컬 Chromium과 실제 Worker 사용.
- `git diff --check`: 공백 오류 없음.

최초 브라우저 재검증 중 개발 서버 연결이 끊겨 페이지가 다시 로드되었고 결과 시간 검사가 한 번 실패했다. trace에서 서버 재연결·문서 재로드를 확인했다. 서버를 별도 유지한 뒤 동일한 전체 시나리오를 재실행해 통과했다. 이 실패를 물리 결과 변경 문제나 CI 사용량 문제로 숨기지 않는다.

## 브라우저와 화면

1. 3개 탐색 공간·고급 설정 숨김 → 군별 체 조건 → Worker FEM/스윕 → 공진 선택 → 입자 계산 → 결과 스크럽 → 공진/입자/실측 연출 → 초기/최종 밀도 → JSON 저장/불러오기 → 조건 변경 무효화.
2. 390×844, DPR 2 환경에서 표준 DPR 상한 1.5와 저사양 DPR 1 전환, 수평 넘침 없음.
3. 분해 연출 스크럽·일시정지·수동 카메라 인계, 조립 복귀, X 단면, 발표 화면 종료 후 구조 상태 유지.
4. v0.2 세션 불러오기, 미디어 출처와 원근 미보정 표기, 모바일 분석/실험 설정 서랍.

스크린샷은 `artifacts/v03-experiment.png`, `v03-analysis.png`, `v03-resonance.png`, `v03-formation.png`, `v03-exploded.png`, `v03-device.png`, `v03-mobile.png`, `v03-mobile-low.png`다. 실제로 열어 이전 `v02-*.png`와 공간 배분·재질·텍스트·Glass 도구를 비교한다. 초기/최종 비교 판이 잘리던 문제는 좁은 렌더 공간의 카메라 거리 보정으로 수정했다.

미디어 테스트의 1×1 PNG는 파일/비교 UI용 fixture다. 실제 실험 사진 검증이나 패턴 정합으로 보고하지 않는다. 이전 UI 전용 테스트는 `tests/legacy/`에 보존했으며 이번 통과 개수에 포함하지 않는다.

## 검증하지 않은 범위

- 실제 실험의 분리 효율·역 클라드니·공기 유동·접촉 마찰·입자 간 상호작용.
- 실제 장비 CAD 정합·볼트 공차·동적 연결 강성, 다른 경계 조건의 실물 클램프.
- 실제 입경 분포/체눈 규격 검증과 이동 계수 보정.
- 원근 보정·영상 패턴의 정량 위치 오차·자동 파라미터 보정.
- 실제 기기 FPS, Safari/Firefox, 모바일 GPU 메모리·열화·접근성 보조기기. SwiftShader/DPR 검사는 렌더 전략 검증이다.
- 영상 녹화·광학 DOF·광학 굴절 셰이더·절단면 캡·완성된 GLB 가져오기.
