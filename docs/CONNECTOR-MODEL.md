# 연결부 등가 모델과 보정

실제 접착부의 강성·감쇠는 아직 제공되지 않았다. 여기서 사용하는 값은 입력된 실측값 또는 출처를 가진 추정값이며, 현재 학교 장치에 대한 검증값을 생성하지 않는다. 연결부 설정이 없는 과거 세션은 기존 중앙 절점 완전 구속 및 기반 변위 응답을 그대로 계산한다.

## 판과 연결부

판은 기존 Kirchhoff–Love BFS FEM과 24개 질량 정규화 모드를 유지한다. 선택적인 유연 연결부는 판 안의 직사각 접촉 영역에서 평균 변위 Bq, 평균 회전 Rxq, Ryq를 사용한다. 형상 함수와 물리 좌표 기울기를 요소 경계마다 분할한 3×3 Gaussian 적분으로 평균한다.

연결부 탄성 에너지는 다음과 같다.

`U = ½ kz (Bq − ybase)² + ½ krx (Rxq)² + ½ kry (Ryq)²`

따라서 판 강성에 `kz BᵀB + krx RxᵀRx + kry RyᵀRy`를 더한다. 원래 중앙 절점 구속은 이 모델을 활성화하면 제거한다. 접촉 영역 전체를 강체 패치로 구속하는 모델은 아니며 접착층 국소 응력이나 전단 박리·이탈을 계산하지 않는다. 편심은 판 좌표의 연결부 위치로 반영한다. 기구 외형의 길이·단면을 바꾸었다고 자동으로 강성을 유도하지 않는다.

연결부 부가 질량은 `m BᵀB`, 회전 관성은 판 평면의 직사각 집중 물체 근사 `Ixx=m h²/12`, `Iyy=m w²/12`를 각각 회전 좌표에 더한다. 연결부 질량 중심의 수직 거리, 수평 운동, 기울기의 중력 프리로드, 진동원의 별도 자유도는 포함하지 않는다. `mass=0`은 해당 효과를 제외했다는 뜻이며 실측 질량 0을 뜻하지 않는다.

점성 감쇠는 같은 평균 좌표에 `cz BᵀB + crx RxᵀRx + cry RyᵀRy`를 사용한다. 모드 공간의 비대각 항도 유지한다. 3개 감쇠 좌표의 저계수 구조를 이용한 Woodbury 축소로 3×3 복소 행렬을 풀며 대각 모달 구조 감쇠와 함께 계산한다.

이 유연 연결부의 기반 변위 하중은 절대 좌표에서 다음과 같다.

`F(ω) = (kz + iωcz) Bᵀ ybase`

따라서 응답에 임의의 강체 이동을 덧붙이지 않는다. 기존 완전 구속 기반 모델만 과거의 상대 응답 + 강체 변위 표현을 유지한다. 직렬 스피커/전달부 자체의 측정된 전달함수나 동적 피치/롤 입력은 아니다.

`kz`는 N/m, `krx/kry`는 N·m/rad, `cz`는 N·s/m, `crx/cry`는 N·m·s/rad, 질량은 kg, 접촉 폭·높이는 m다. 메타데이터와 추정 범위는 고유치 키에서 제외한다. 강성·질량·접촉 영역·위치는 FEM을 무효화하고 감쇠만 바뀌면 고유모드를 재사용해 응답을 갱신한다. 수치적으로 비양의 고유값이나 큰 잔차가 발생하는 극단적인 강성 대비는 오류로 거부한다.

스프링·점성 감쇠·회전 관계 및 가상일에 관한 방법 근거: [COMSOL Spring Foundation and Thin Elastic Layer](https://doc.comsol.com/6.4/doc/com.comsol.help.sme/sme_ug_theory.06.068.html). 이 구현의 평균 패치·집중 질량 근사는 해당 제품의 완전한 기초층 모델을 복제한 것이 아니다.

## 보정

`CalibrationPanel`은 사용자 입력/CSV의 모드 번호, 주파수, 출처, 선택적인 ±Hz 불확도와 보정/독립 검증 용도를 받는다. 숫자가 없는 100 Hz 설탕 관찰을 임의의 모드 번호에 연결하지 않는다. 모드 형상의 대응은 사용자가 확인한다.

수직 강성 kz 또는 두 회전 강성의 공통 배율 중 1개 변수만 지정한 구간 안에서 보정한다. 9점 로그 탐색과 유한한 golden-section 세부 탐색을 Worker에서 실행한다. 서로 다른 모드의 보정 관측이 최소 2개 필요하다. 독립 검증 행은 목표 함수·탐색에 들어가지 않는다. 주파수 불확도를 입력하면 역분산 가중 잔차를 사용하고, 미입력 행은 상대 오차로 평가한다. 선택 모드가 해당 강성에 거의 민감하지 않으면 식별 불가로 중단한다.

출력은 원래/보정 Config, 사용한 전체 관측, 행별 계산−실측의 Hz/상대 오차, 보정/검증 RMS, 탐색 구간/경계 도달, 평가 횟수다. 원래 입력은 수정하지 않는다. 실제 장치 프로필의 측정값도 덮어쓰지 않으며 보정된 계산 파라미터와 원래 증거를 구별한다. 보고서 JSON을 내보낼 수 있다.

공진 피크 주파수를 무감쇠 고유주파수의 근사로 취급한다. 강한 감쇠·중첩 공진·모드 교차에는 오차가 생길 수 있다. 모드 형상 MAC 대응·다변량 베이지안 추정·미지 스피커 전달함수 보정은 구현하지 않는다. 검증 자료의 실험적 독립성과 측정값의 신뢰성은 사용자의 실험 기록에 달려 있다. 작은 보정 오차만으로 디지털 트윈의 실물 정확도를 인증하지 않는다.

별도의 반전력 도구는 고립된 약감쇠 단일 공진의 `ζ≈(f₂−f₁)/(2f₀)`만 적용한다. 두 반전력 주파수와 정점, 자료 출처를 모두 요구하며 원래 판 감쇠에 적용할 때 그 입력을 `Plate.dampingSource`에 보존한다. 주파수 고유치만으로 감쇠를 추정하지 않는다.

## 실행한 검증

`node --import tsx --test tests/connector.test.ts`의 7개 테스트가 통과했다. 패치의 강체 이동·선형 회전 재현, 준정적 기반 추종, 강성/질량/면적 민감도, 해석 SDOF 절대 전달률, 2모드 비대각 감쇠의 직접 복소해와 비교, 캐시 구분, 1변수 합성 보정 및 검증 데이터 제외, 반전력 입력 검증을 포함한다. 합성 보정 데이터는 솔버에서 만든 테스트 fixture이며 실제 실험 데이터가 아니다. 기존 36개 테스트도 연결부 추가 직후 통과했다.
