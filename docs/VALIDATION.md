# 검증 기록

2026-11-12 · v0.1

## 빌드와 수치 검증

- `npm run build`: TypeScript 검사와 Vite 정적 빌드 통과.
- `npm test`: 8개 통과.
- 장의 반대칭성·중앙 상대변위, 수치 미분과 해석 기울기 일치, 입자의 마디 접근과 판 경계, 결정적 역 스크럽, 모드 간 동일 초기 배치, 역 개념 모델의 배 접근, 주파수 응답, 유한한 등고선 좌표를 확인했다.

## 브라우저 검증

`npm run test:browser`: 5개 시나리오. 로컬에 설치된 Chromium을 SwiftShader WebGL로 구동했다. 자동화 환경의 브라우저 실행 파일 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 주입했고 프로젝트에 절대 경로를 고정하지 않았다.

1. 구조·분석 뷰 전환, WebGL 초기화, 실행 오류 확인.
2. 분해도·진폭 분포·비교·클린 장면 캡처.
3. 모드·주파수·재질·시간·재생·레이어·선택·PNG·JSON 저장.
4. 직접/역·실험 기록·전/후·시간 변화 비교와 로컬 이미지 불러오기.
5. native dialog, 클린 모드, 데모 전용 조건과 종료 시 복귀, 모바일 설정 패널과 가로 넘침 확인.

데스크톱 1512 × 982, 모바일 390 × 844에서 스크린샷을 검토했다. 카메라 전환을 경과 시간 기반으로 바꾸고, 좁은 화면과 분할 화면에서 판이 잘리지 않도록 거리를 맞췄다. 생성한 리뷰 이미지는 `artifacts/`에 있다.

## 공개 전 남은 작업

- 실제 장비 치수·모드·주파수·구동 응답의 계측 및 보정.
- 건식 / 유체 실험 조건별 입자 이동 법칙과 분리 성능 검증.
- 실험 영상과 시뮬레이션의 시간 동기화, 촬영 원근·스케일 정합.
- CAD 단면 캡·해칭, 제조 상세·공차와 실제 구동부의 정합 검토.
- Safari / Firefox / 실제 iPhone·Android GPU에서 조작·메모리·FPS 검증.
- 저사양 품질 단계, GPU 입자 갱신, WebGPU 백엔드.

빌드에는 두 JavaScript 청크가 500 kB를 넘는다는 크기 경고가 있다. 압축 전 Three.js 약 525 kB, 앱·면광원 LUT 약 551 kB이며 gzip은 각각 약 133 / 199 kB다. 오류는 아니지만 게시 전 로딩 성능을 측정하고 필요하면 초기 안내 화면과 3D 모듈을 지연 로딩한다. 정지 상태에서는 장면 갱신을 생략하고, 숨겨진 탭에서는 렌더와 타임라인을 멈춘다.

이 기록은 수치 해석의 물리적 검증이나 대상 기기의 60 FPS 보장을 의미하지 않는다. 현재 결과물은 실행 가능한 시각화 초안이다. 웹 배포와 실험 데이터 전송은 수행하지 않았다. GitHub CI가 사용량 한도로 실행되지 않는 경우는 코드 오류와 별도로 취급한다.
